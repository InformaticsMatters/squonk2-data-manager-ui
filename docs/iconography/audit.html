Data Manager UI — iconography audit

Stage one for #200 (Icons): every app function, the icons it uses today, and where an icon could make it clearer. Grouped by function; each lists the pages it appears on. All current icons are @mui/icons-material (rendered here from the installed package). Rows marked (MUI internal) are drawn by MUI components themselves, not imported by the app. Choosing the replacement set is the next stage.

Priority: High meaning is unclear or wrong today, or a core concept has no icon. Medium would aid scanning or consistency. Low polish.
