# Documentation

The **Squonk Data Manager** is a managed environment for your data, and for the workflows,
applications and jobs that work on it. These pages explain what it is made of and how to use it.

If you have never used it before, read **Concepts** for the vocabulary, then take the **Guided
tour**. If you know what you are looking for, the **How-to guides** are arranged the same way the
application is: one guide per workspace, and one guide per section of a project.
