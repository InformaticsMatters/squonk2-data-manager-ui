# Logging in

To do anything useful in the Squonk Data Manager you must be authenticated. Squonk uses
[Keycloak](https://www.keycloak.org/) as a Single Sign On (SSO) solution. To be able to use Squonk
you must first have an account in the appropriate Keycloak instance and then log in using your
username and password (or whatever other mechanisms that Keycloak instance might offer, such as
"log in with Google").

The Keycloak instance might allow you to register yourself with an account, or might require you to
contact an administrator to set up the account for you before you can use it.

Once you have an account you can log in to the Squonk Data Manager using the **Account** menu in the
top right corner and choosing **Login**. That will take you to Keycloak where you can authenticate (the exact details of the authentication
options may differ from this example):

<Image src={keycloak} alt="Keycloak login" />

## Where you land

You are returned to the page you were on when you signed in, including the exact resource and view
it named, so a link someone sent you survives being logged in to reach it.

## What the Account menu shows

Once signed in, the **Account** menu shows your username, the Data Manager and Account Server roles
your account holds, the colour scheme selection, and a control that shows or hides the event stream.

## Logging out

To log out use the same **Account** menu and choose **Logout**. Signing out clears the
account-scoped state this browser was holding, including the organisation you were working as.

## After your first login

Signing in is not by itself enough to start work: you also need a project. If you have none, see
[Getting started](/docs/how-to/getting-started).
